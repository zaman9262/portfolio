# portfolio:Web アプリケーションのプロトタイプ
生成AIをプログラミングパートナーとして活用し、ローカル環境（Apache）で動作するWebシステムのプロトタイプを作成しました。

## 開発の背景・目的
インフラの自動化やコンテナ技術、Webサーバーの仕組み（Apache）を実体験しながら学ぶことを目的として作成しました。

## 使用した技術・環境
ー使用した言語：HTML/CSS
ー動作環境：ローカル環境（Apache）
サポートツール：生成AI（チャートGPT等）
